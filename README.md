# bot-paris

Suivi en direct des paris de l'analyste : toutes les 5 minutes, lit les paris en attente, suit le score en direct et envoie les notifications Telegram (début, buts/sets, pari passé, perdu, remboursé). Le résultat est écrit dans Notion pour mettre l'appli à jour.

Secrets nécessaires (Settings → Secrets and variables → Actions) : `NOTION_TOKEN`, `TG_TOKEN`, `TG_CHAT`.
